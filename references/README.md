# References

Vendored copies of external repos kept here purely for local reference —
design/frontend-quality skills and tooling that inform how this site is
built. Each is a snapshot (no `.git` history, no upstream tracking); pull a
fresh copy from the source repo if you need updates.

None of this code is authored by this project. All credit belongs to the
original authors below.

## Contents

### [taste-skill](https://github.com/Leonxlnx/taste-skill) — MIT, © 2026 Leonxlnx
Anti-slop Agent Skills for premium frontends — a Claude Skill that pushes
AI-generated frontend work away from generic "AI slop" toward considered,
high-taste design.

### [impeccable](https://github.com/pbakaus/impeccable) — Apache-2.0, © pbakaus
Design guidance for AI coding agents: 1 skill, 23 commands, live browser
iteration, and 61 deterministic detector rules for catching AI-generated
frontend design problems.

### [awesome-design-md](https://github.com/VoltAgent/awesome-design-md) — MIT, © 2026 VoltAgent
A curated list of design-focused Markdown skills/resources for AI coding
agents.

### [img2threejs](https://github.com/img2threejs/img2threejs) — Apache-2.0, © img2threejs
Rebuilds the object in a reference image as a code-only, procedural
Three.js model — a Claude Skill for image-to-3D workflows.
